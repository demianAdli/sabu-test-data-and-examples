# `jug_gis_cities` Examples

This folder contains instructions for running the `mtl_fsa_gisoo` component
directly from Python.

- [direct_python/](direct_python/README.md): configure standalone PyQGIS,
  install local Sabu packages, and run the prepared districts.

Start by placing the six prepared GeoPackages in
[`../datasets/mock_data/`](../datasets/mock_data/), following the
[input inventory](../datasets/README.md). Then follow the direct Python guide.
Service code is installed from the main Sabu checkout; this repository holds
the example inputs, outputs, and instructions.
